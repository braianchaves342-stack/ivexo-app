# Bienvenida a IVEXO

Un espacio de trabajo modular, sobrio y propio.

- Explorador web con cápsulas independientes
- Documentos editables guardados en workspace
- Archivos persistentes y compartidos entre instancias
- Stream, cálculo y consola Jenny

## Arquitectura

Las cápsulas se pueden mover, redimensionar y ordenar libremente.
